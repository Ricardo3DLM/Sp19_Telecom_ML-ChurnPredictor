### Para entornos nuevos:
### Crear entorno (environment):
# python -m venv [nombre_de_env]
#--------------------------------------------
### Activar entorno:
# [nombre_de_env]/bin/activate.bat 	(si no funciona, borrar ".bat")
#--------------------------------------------
### Revisar requisitons/programas instalados:
# pip list
#--------------------------------------------
### Instalar requisitos:
# pip install -r requirements.txt
#--------------------------------------------
### Para guardar nuevo requirements.txt:
# pip freeze > requirements.txt
#--------------------------------------------
### Para salir de entorno:
# deactivate
